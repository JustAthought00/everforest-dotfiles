# Everforest menus

Layouts inspired by zDyant/HyprNova (MIT), with an independent Everforest palette.
Source reference: https://github.com/zDyant/HyprNova

- base.rasi: shared colours, typography, search field and cards
- wallpaper.rasi: wallpaper gallery
- clipboard.rasi: searchable clipboard history
- power.rasi: power-action cards
- confirm.rasi: action confirmations

Existing keyboard shortcuts are unchanged. No pywal dependency is required.
